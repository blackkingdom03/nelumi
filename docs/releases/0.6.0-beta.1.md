这次把 nelumi 带到更多电脑上。原来的日历、通知提取、图片识别、生日提醒和笔记继续保留。

同时修正了纯日期在负时区可能落到前一天的问题。中国日历中的日期现在按日历当天读取，并增加了四个时区的回归检查。

## 选哪个文件

| 你的电脑 | 下载文件后缀 | 使用方法 |
| --- | --- | --- |
| Windows，Intel / AMD | `windows-x64-setup.exe` 或 `windows-x64.zip` | 安装版按向导操作；便携版完整解压后运行 nelumi.exe |
| Windows，ARM / 骁龙 | `windows-arm64-setup.exe` 或 `windows-arm64.zip` | 不确定时，在系统设置的“系统类型”中查看 |
| Mac，M 系列芯片 | `macos-arm64.dmg` | 打开后将 nelumi 拖到“应用程序” |
| Mac，Intel 芯片 | `macos-x64.dmg` | 在“关于本机”中查看处理器 |
| Linux，Intel / AMD | `linux-x64.AppImage` 或 `linux-x64.deb` | AppImage 需要执行权限及 FUSE；DEB 适用于 Ubuntu / Debian |

文件名前面都有 `nelumi-0.6.0-beta.1-`。不需要下载 Source code。`SHA256SUMS.txt` 用于核对下载文件是否完整。

## 这次验证了什么

只有五组构建全部通过，才会自动发布这一版。每组都在对应系统和芯片的 GitHub 测试机上运行自动测试，并启动打包后的程序，检查月历显示、日程写入、文件保存，以及随包 OCR 识别日期和时间。

这仍是**多平台测试版**。自动检查不等于已在所有电脑上试用：真实通知权限、休眠后提醒、开机启动、桌面透明效果与托盘仍需要日常使用验证。Linux 的显示效果也会受桌面环境和 Wayland / X11 影响。

Windows 和 Mac 安装包尚未取得开发者代码签名，Mac 版未经过 Apple 公证，系统可能阻止首次打开。请只从本仓库下载；不建议关闭系统整体安全保护。需要已签名安装包的用户请先继续使用原版本或等待后续版本。

## 数据怎么保存

- Windows 延续原来的方式：程序旁的 `data/`。升级前先备份；使用便携包时完整解压，保留自己的 data 文件夹。
- Mac 使用 `~/Library/Application Support/nelumi/`。
- Linux 使用 `$XDG_CONFIG_HOME/nelumi/`，通常是 `~/.config/nelumi/`。
- 可以通过“数据与备份”导出、导入日程。多设备之间暂时不会自动同步。

Linux 关闭按钮会最小化到任务栏，避免没有托盘的桌面环境找不回窗口；Linux 暂不启用鼠标穿透。提醒需要程序保持运行，关机或退出期间无法发出通知。
