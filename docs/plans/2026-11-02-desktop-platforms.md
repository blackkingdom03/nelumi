# 已确认的电脑适配方案

用户选择先做 Windows、Mac、Linux，并确认五类设备、八个下载包的方案。

保留现有日程与功能，Windows 数据路径保持兼容；Mac / Linux 使用用户配置目录。分别适配开机启动、菜单与窗口唤起。复用现有 Electron / electron-builder，无新运行时依赖。

构建在对应系统的原生芯片 runner 上进行。每组运行现有单元测试和打包后启动检查，覆盖日程写盘及 OCR。全部成功后发布多平台 beta，说明人工验证与签名范围。原稳定版不替换；用户电脑上运行的日历不重启、不覆盖。

验收：八个文件均可下载，文件名明确区分设备，校验和齐全；README 与发布页写明数据位置和测试边界。
